# Numeric-Project 🧮

A collection of numerical method simulations used to solve physics problems using Python and Jupyter Notebook.

## 📚 Contents
- `Atom_Infinite_Well_Potential.ipynb`: Solving quantum well model with Numerov's Method
- `Bessel_Function.ipynb`: Visualization of Bessel functions
- `Calculate_Square_Root_(1+x).ipynb`: Numerical approximation of square root
- `Osilasi_Teredam_pada_Medium_Visko_Python.py`: Damped oscillator simulation with Runge-Kutta 4's method
- `Probability_Posistion_of_Electron_Wavefunction_Python.py`: Quantum probability visualization

## 🛠 Tools
- Python
- Jupyter Notebook
- Matplotlib, NumPy, SciPy

## 🔍 Topics Covered
- Numerical integration
- Differential equations
- Quantum mechanics
- Data visualization
- Numerical Method
